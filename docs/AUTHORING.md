# UNSTRUNG — Content Authoring Guide

Everything in the world is data. Rooms are ASCII grids, enemies are definitions combining an AI
**behavior** with a parametric **art body**, and bosses are small classes that script attacks as
coroutines. Read `docs/DESIGN.md` for the game, and `docs/WORLD.md` for the area plan.

---------------------------------------------------------------------------------------------------
## 1. Rooms

Each area has one file, `src/data/rooms/<area>.js`, that default-exports an array of room defs:

```js
export default [
  {
    id: 'hollows_04',            // unique; prefix with the area id
    area: 'hollows',
    name: 'Bellrope Drop',        // optional, shown on the map
    music: 'hollows',             // optional (defaults to the area's track)
    dark: false,                  // true = pitch dark without the Glowwick Lantern
    req: ['sap'],                 // optional: abilities to validate this room with (default: area tier)
    lockedDoors: ['3'],           // optional: doors intentionally unreachable with `req` (need later abilities)
    deadEnd: ['2'],               // optional: entries that are allowed to have no other exit (e.g. treasure nooks)
    legend: {
      a: { e: 'enemy', id: 'mossgrub' },
      s: { e: 'spindle' },
      k: { e: 'item', item: 'shellFrag', needs: ['dash'] },
    },
    doors: { 1: 'hollows_03:2', 2: 'hollows_05:1' },
    tiles: [
      '########################################',
      '#                                      #',
      // ...
    ],
  },
];
```

### Tile characters

| char | meaning |
|---|---|
| ` ` or `.` | empty air |
| `#` | solid rock (drawn as the area's ink-outlined terrain) |
| `=` | one-way platform (stand on it, jump up through it, Down+Jump drops through) |
| `/` `\` | 45° slopes. `/` rises to the right: solid in the lower-right half. `\` rises to the left. Always put `#` under a slope, and `#` beside its high side. |
| `^` | spikes or thorns (hazard: 1 Shell damage, then respawn at the last safe ground). Bead can pogo off them with a down-Bonk. |
| `~` | water (swimmable; Jump strokes upward) |
| `!` | ink or acid: hazard without **Glass Shell**, swimmable with it |
| `B` | breakable wall (3 Bonks). Use it for secrets and shortcuts. |
| `G` | cracked floor, broken only by **Lead Heart** (ground pound) |
| `C` | crystal block, broken only by **Comet Roll** |
| `M` | magnetic copper surface: with **Lodestone**, Bead sticks to it and rolls along walls and ceilings |
| `H` | half-block (top half solid). A 1-tile-tall gap under a row of `H` is a crawlspace only **Pinhole** (shrunk Bead) fits through. |
| `O` | grapple hook ring for **Spool Line** (non-solid). Range is about 6 tiles. |
| `W` | updraft column: carries Bead upward while gliding with **Dandelion** |
| `I` | ice: solid, slippery, and you can't wall-cling to it |
| `*` | fake wall: drawn as rock, but passable, and reveals itself when Bead enters (secret rooms!) |
| `0`–`9` | door cells (must be on the room border, see below) |
| `@` | player start (only the very first room of the game) |
| any letter | entity marker, defined in `legend` (the cell itself is empty air) |

### Room size & camera
- The screen shows **30 × 17 tiles** (tile = 32 px). Minimum room size is 30 × 17.
- Typical rooms are 40–100 wide and 17–60 tall. Use tall shafts and wide halls. Keep under 160 × 100.
- Keep every row the same length. Put solid `#` around the whole border except at doors.

### Doors
- Door cells are digits placed **on the border**. A side door is ≥2 cells tall, 3–4 is typical.
  A top or bottom door is ≥2 cells wide.
- The cells of a side door sit directly **above floor**: Bead arrives standing on the tile below the
  door's lowest cell, so put solid ground under a side door, extending at least 3 tiles inward.
- `doors: { '1': 'otherRoom:3' }` links door 1 to door 3 of `otherRoom`. Links **must be reciprocal**,
  and edges must face each other (right ↔ left, bottom ↔ top). Linked doors should be the same width.
- Entering through a **bottom** door (coming up from below) gives Bead an upward boost of about 4 tiles.
  Leave a ledge beside the opening so the player can land. Entering through a **top** door means falling in.
- The map is generated by aligning linked doors, so make rooms geometrically consistent: if room A's
  right door is at rows 10–12, room B's left door should line up with it.

### Bead's movement (design metrics)
| move | reach |
|---|---|
| Jump (hold for full height) | up **4 tiles** reliably (5 is impossible). Across a flat gap: up to **5 tiles** comfortably, 6 is a hard max. |
| Short hop | ~1.2 tiles |
| Sticky Sap (wall cling/jump) | climb any non-ice wall. Two walls 3–6 tiles apart make a climbable shaft, and a single wall can be climbed by wall-jumping back into it. |
| Pebble Dash | +4 tiles horizontally, usable once in air (reset by ground, wall, pogo, or hook) |
| Running dash-jump | about 9 tiles across |
| Dandelion glide | falls slowly (~115 px/s). From a height of N tiles you can drift about 2.5×N tiles sideways. Updrafts `W` carry you up while gliding. |
| Bubble Hop (double jump) | +3.5 tiles. A full jump plus a double jump clears **7 tiles** up. |
| Lodestone | ride `M` walls and ceilings anywhere |
| Comet Roll | flies horizontally, ignoring gravity, until it hits a wall. Smashes `C`. Can cross any gap. |
| Pinhole | 12×12 px body: fits through `H` crawlspaces, jumps ~2.5 tiles |
| Spool Line | zip to any `O` within ~6 tiles with line of sight, then hang. Jump from the hang rises ~4.5 tiles. Chain hooks for long crossings. |
| Pogo | a down-Bonk on an enemy or on spikes bounces Bead up ~3 tiles and refreshes dash and double jump |

### Entity legend types
| `e:` | fields | notes |
|---|---|---|
| `enemy` | `id`, optional `facing`, `params` overrides, `hpMul` | place on the floor tile **just above the ground** (ground enemies). Flyers can float anywhere. |
| `boss` | `id` (from `src/data/bossinfo.js`), optional `arena:{x,y,w,h}` (px), `trigger:{x,y,w,h}` (px) | the fight starts when Bead walks into the arena |
| `gate` | `h` (tiles tall, default 3), `w` (default 1), and one of: `arena:true` (closes during a boss fight), `flag:'name'` (opens when a lever sets that flag; use `flag:'boss_<id>'` to open after a boss dies), `item:'lantern'` (opens if the player has that key item), `beads:6` (needs Great Beads) | the marker is the gate's top-left tile. Leave the gate's cells empty in the grid. |
| `lever` | `flag` | hit it to set the flag. Pair it with a `gate` in the same or another room (classic one-way shortcut). |
| `spindle` | – | bench: rest, save, heal, swap Knots. Place one every 4–6 rooms, always one 1–2 rooms before a boss. |
| `item` | `item`: `shellFrag`, `vesselFrag`, `knot` (+`id`), `notch`, `ore`, `ability` (+`id`), `greatBead` (+`id`), `key` (+`id`), `map` (+`id`=area id, `name`), `glints` (+`value`); optional `needs:[abilities]` | floating pickup. Use `needs` when it is behind a later ability (backtracking reward). |
| `beadling` | – | a lost Beadling in a jar (48 in the world) |
| `lore` | `id` (key into `src/data/lore.js`) | Threadscript tablet |
| `npc` | `id` (key into `src/data/npcs.js`), optional `facing` | |
| `pot` | `value` (glints), `cache:true` for a big glint deposit | breakable |
| `ferry` | `id` (area id) | Moth Ferry station: one per area, near a spindle |
| `deco` | `kind`: `lamp`(+`hang:true`), `candle`, `statue`, `sign`(+`text`), `banner`(+`color`), `bones`; `front:true` draws in front | pure decoration |
| `trigger` | `w`,`h` (tiles), `flag`, `hint`/`desc` (banner) or `text`(+`speaker`) (dialogue) | invisible tutorial or story trigger |

`needs: [...]` on any legend entry tells the validator that this entity is reachable only with
those extra abilities.

### Validating
```
node tools/validate.js --area hollows          # static + reachability for every room in the area
node tools/validate.js --room hollows_04       # one room
node tools/validate.js --room hollows_04 --ab sap,dash   # with a specific ability set
```
The validator simulates Bead's real physics, so trust it. Each room must have:
- 0 ERRORs.
- No warnings about unreachable doors or items, unless they are intentionally behind a later ability. In that case, mark the door in `lockedDoors` and the item with `needs`.

### Level design principles (Hollow Knight / Silksong style)
1. **Every room has a purpose**: a platforming challenge, a combat arena, a vista, a secret, a shortcut,
   a lore tablet, or an NPC. Vary the shapes: long halls, tall shafts, zig-zags, caverns with
   multiple levels, small secret nooks.
2. **Ability gates are visible before they can be passed**: show the high ledge, the crystal wall,
   the ink lake, or the hook ring the player can't use yet. Reward coming back later.
3. **Loops and shortcuts**: levers that open gates back to a spindle; breakable walls connecting
   back to earlier rooms.
4. **Secrets**: `*` fake walls and `B` breakable walls hiding beadlings, knots, glints and lore.
   Hint at them with an odd gap or a lone decoration.
5. **Hazard platforming**: spike pits with pogo enemies, spike corridors needing precise wall jumps.
   Late areas should be HARD (Path of Pain energy in optional rooms).
6. **Enemy placement**: 2–6 enemies per room, mixing ground and air types. Don't put enemies right
   at a door entrance.
7. **Boss arenas**: at least 40 wide and 17 tall. Mostly flat, with a few platforms for dodging. Arena
   gates (`{e:'gate', arena:true}`) go just inside each door. Put a spindle within 1–2 rooms.

## 2. Enemies

One file per area: `src/data/enemies/<area>.js`, default-exporting an array:

```js
{ id: 'mossgrub', name: 'Mossgrub', area: 'hollows', hp: 12, dmg: 1, glints: 3,
  size: [32, 20],                       // hitbox px (w, h)
  behavior: 'crawler', params: { speed: 50 },
  art: { body: 'grub', c1: '#3f6b5c', c2: '#9fe0c4', c3: '#e8e2d0', eye: '#ffffff', mask: true },
  weight: 1,                            // knockback resistance (heavy = 3+, immovable = 99)
  journal: 'Two sentence hunter-journal entry, in-world voice.', kills: 15 }
```

**HP & damage by tier**: early (fray, hollows, town) has hp 8–20, dmg 1. Mid (gardens through cistern) has hp 18–45, dmg 1.
Late (kilns through frost) has hp 35–90, dmg 1–2. Endgame (loom, unwoven, cradle) has hp 60–140, dmg 2.
The Bonk does 5 damage at first and rises to 21.

### Behaviors (`src/entities/behaviors.js`)
| behavior | what it does | params (defaults) |
|---|---|---|
| `crawler` | walks back and forth, turns at walls and ledges | speed 50, noLedge |
| `critter` | harmless, flees | speed |
| `charger` | spots Bead on the same level, winds up, charges | speed 45, chargeSpeed 380, sight 320, tele .45 |
| `hopper` | hops around and toward Bead | interval 1.3, vx 170, vy 620 |
| `leaper` | small hops, then a big telegraphed leap at Bead | interval, vx, vy, leap 760, sight |
| `flyer` | floats, chases when it sees Bead | speed 110, accel 320, sight 360, bob |
| `swarm` | jittery small flyer, use in groups | speed 170, accel 600 |
| `swooper` | hangs from the ceiling, swoops in an arc | speed, sight, range 220 |
| `shooter` | stationary ground turret, telegraphed shots | interval 2.2, speed 260, count 1, spread .25, arc false, gravity, color, projArt |
| `flyshooter` | flyer that keeps distance and shoots | speed, keep 210, interval, projSpeed, count, spread |
| `wallcrawler` | crawls around terrain surfaces (place it on a surface) | speed 55 |
| `burrower` | hides underground, emerges under Bead | sight 230, speed 140, up 1.2 |
| `dropper` | hangs on the ceiling, drops when Bead passes below, then crawls | range 50, speed |
| `guard` | armed husk: approaches, winds up, lunges with a weapon. Set `shield:true` to block frontal Bonks (hit it from above or behind). | speed 55, sight, lunge 280, reach 46, tele .42, shield |
| `lancer` | long telegraphed thrust | speed, sight, reach 110, tele .55 |
| `bomber` | flies above Bead and drops bombs | speed, interval, height 150 |
| `exploder` | rushes Bead and explodes after a fuse | speed, rush 230, fuse .7, radius 64 |
| `spawner` | births minions (`child: enemyId`) | interval 4, max 3, child |
| `spinner` | rotating bullet-pattern turret | rate, speed, arms 4, interval .3 |
| `orbiter` | circles its spawn point (ignores walls) | radius 64, speed 2.2 |
| `phaser` | ghost: fades, reappears beside Bead, dashes | interval 2.4, dash 420 |
| `mimic` | pretends to be scenery, then pounces | wake 90 |
| `swimmer` | lives in water or ink, lunges | speed, lunge 360 |
| `roller` | an evil little ball: rolls fast and bounces | speed 210, hop 520 |
| `sentinel` | invulnerable shell, opens to shoot (vulnerable while open, or to a ground pound) | open, closed, count, spread |
| `lasher` | rooted plant: lashes toward Bead in range | range 120, tele .5 |
| `thrower` | lobs arcing globs | interval, speed 400, gravity 1000, count |
| `stalker` | chases on the ground, jumps after Bead | speed 150, jump 720 |
| `dasher` | hovering flyer that dashes in straight lines | speed 520, interval 2 |
| `hazard` | invulnerable harmful object (e.g. spinning sawblade) | – |

Projectile art (`projArt` param): `orb`, `glob`, `needle`, `flame`, `feather`, `shard`. Set `color` too.

### Art bodies (`src/art/creatures.js`)
`mite, grub, beetle, slug, snail, moth, fly, spider, jelly, knight, hopper, worm, shroom, crystal,
gear, fish, bird, bat, wisp, candle, skull, wasp, crab, mantis, golem, bell, book, spool, eyeball,
flower, yarn, ball, icicle, beast`.

Common art params: `c1` (main), `c2` (accent), `c3` (mask/detail), `eye` (eye color), `glow: true`
(glowing eyes), `centered: true` (**required for flyers and floaters**), `scale`, and per-body extras:
`mask` (grub), `segs` (grub), `spikes` (grub/beetle/ball), `horn` (beetle 1–3), `shell` (slug),
`wing: 'moth'|'bat'|'fly'` (moth), `stinger` (fly), `eyes` (spider count), `weapon: 'nail'|'spear'|'shield'`
and `horns: 0` (knight), `teeth` and `lure` (fish), `n` (crystal count), `teeth`/`spin` (gear).
Sizes drive the drawing, so a `[60,50]` knight is a big brute.

Make every enemy **visually distinct** within its area: different body, palette, size, or features.
Use the area palette (see `src/art/palettes.js`) with one strong accent color.

## 3. Bosses

See `src/bosses/boss.js` (base) and `src/bosses/fray.js` (Gnarlknot, the reference). A boss is a class:

```js
export class Petalmaw extends Boss {
  constructor(game, tx, ty, spec) {
    super(game, tx, ty, spec, { id: 'petalmaw', size: [120, 140], music: 'boss_gardens', air: false });
  }
  attackList() { return [ { name: 'bite', w: 2, fn: this.bite, cond: () => this.distX() < 200 }, ... ]; }
  *bite() { this.tele = 0.5; yield 0.5; this.zone(x, y, w, h, 0.2); yield 0.6; }
  onPhase(n) { ... }            // hp thresholds (default 66% and 33%)
  bodyBox() { return {x,y,w,h}; }   // hurtbox + contact damage box
  drawBody(ctx, t, white) { ... } // white=true: draw as flat white silhouette (hit flash)
}
```
Name, epithet, hp and rewards come from `src/data/bossinfo.js`.

Helpers: `yield n` waits n seconds, a bare `yield` waits one frame, and `yield* this.leapTo(x, height, time)`,
`yield* this.dashTo(dir, speed, maxDist)` and `yield* this.moveTo(x, y, speed)` are sub-coroutines.
Spawners: `this.fire(x, y, vx, vy, opts)`, `this.fireAt(x, y, speed, opts)`, `this.fireRing(x, y, n, speed, opts)`,
`this.zone(x, y, w, h, life)` (damage rect), `this.shockwave(x, dir, speed)`, `this.summon(enemyId, tx, ty)`.
Utilities: `this.facePlayer()`, `this.distX()`, `this.dirTo()`, `this.player`, `this.arena`, `this.groundY`, `this.phase`,
`this.tele = seconds` (wind-up glow), `this.shake(mag, t)`, `this.sfx(name)`, `this.fx` (particles), `this.rand`, and `this.pick`.
`this.hits.push(rect)` adds a damaging rect for this frame (weapons). It's cleared every frame.
`this.air = true` or `cfg.air` means flying (no gravity). Set `this.noPhysics = true` to fully control position.

**Every attack must be telegraphed** (≥0.35 s wind-up, with a visual like `tele`, a pose, or a flash) and
must be dodgeable with the abilities the player has at that point. Bosses get faster and add attacks
with each phase. Echo versions (Hall of Echoes) automatically get ×1.45 HP and ×1.22 speed.

Drawing: use `src/art/creatures.js` helpers (`INK`, `eye()`), ink outlines (lineWidth 2–4, color INK),
and pale masks. Draw at `this.cx`, `this.y + this.h`, and so on. When `white` is true, use `#fff` for every
fill and stroke.
